# greek-core-vocab

A reusable pipeline: fetch [Perseus's Greek Vocabulary
Tool](https://www.perseus.tufts.edu/hopper/vocablist?lang=greek) weighted-
frequency word lists for every *Great Books of the Western World* work that
has a matching Greek text on Perseus, and combine them into one master
core-vocabulary frequency list.

(Full pipeline documentation to follow as the stages are built.)
