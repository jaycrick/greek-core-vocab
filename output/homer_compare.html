How to read this

Both top-100 lists are ranked by their own count, then percent is computed against that list's own top-100 sum as denominator — not either source's full Iliad+Odyssey vocabulary. The vocab.perseus.org ranking sums each headword's exact count across the Iliad and Odyssey CTS URNs in master_vocab.csv's source_urns. The WordHoard ranking sums data/homer_counts.json's lemma_counts for homer:IL/homer:OD (NFC-normalized), the same hand-disambiguated tagging jaycrick/ag-cloze-cards's own Homer Anki deck is built from.
  • Both are counting the SAME two texts, so a large gap for a given lemma points at a real tagging difference, not a genre/corpus-composition effect (unlike a cross-corpus comparison).
  • vocab.perseus.org's own catalog already carries the proper-noun headwords (Ἀχιλλεύς, Ἕκτωρ, Ὀδυσσεύς) that used to be this pipeline's whole reason for reaching for WordHoard instead -- confirmed directly against the old hopper's fetched data, which lacked them entirely.
  • vocab.perseus.org's token totals run somewhat higher than WordHoard's exact count (Iliad: 123,113 vs. 111,710, 10.2% apart; Odyssey: see the stats above) -- vocab.perseus.org's count includes forms WordHoard's stricter epic-dialect tagging may split differently or exclude.
vocab.perseus.org: output/master_vocab.csv rows touching the Iliad/Odyssey URNs, ranked by count · WordHoard: data/homer_counts.json (homer_vocab.py, via jaycrick/ag-cloze-cards's own WordHoardHomerAdapter), Iliad+Odyssey summed by lemma · percentages are each list's own top-100 share, not a share of either source's full count.
